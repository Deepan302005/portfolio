Automatic License Plate Recognition (ALPR)

A high-performance computer vision system developed to detect vehicle number plates in live video streams, isolate plate regions using bilateral filtering and edge contours, and extract alphanumeric registration text using deep learning EasyOCR for real-time traffic and parking intelligence.

🏢 Developed during Software Engineering Internship at Tunga Aerospace Pvt Ltd, Chennai (Feb - Mar 2025)
🚀 Launch Interactive Demo 📦 GitHub Repository Architecture: OpenCV • EasyOCR • 45+ FPS
📋 Project Overview & Objectives
🎯 Problem Statement

Highways, toll plazas, and automated security gates require instantaneous vehicle plate identification to prevent traffic congestion and human logging errors. Variable daylight conditions, motion blur, and dirty plates cause conventional OCR to fail without optimized edge preprocessing.

🚀 Project Objectives
  • Real-Time Video Detection: Detect license plate coordinates in live camera feeds at 45+ FPS with low latency.
  • Noise-Resilient Preprocessing: Apply grayscale conversion, bilateral smoothing, and Canny edge detection.
  • High-Precision Character Recognition: Extract alphanumeric plate strings with 98%+ confidence using EasyOCR.
  • Automated Telemetry Logging: Record timestamps, vehicle categories, and confidence metrics for audit trials.
