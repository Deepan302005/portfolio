Intelligent Academic Assistant & Quiz Engine

An AI-powered academic assistant engineered to ingest courseware PDFs, create semantic vector embeddings, and retrieve accurate context-grounded responses using a Retrieval-Augmented Generation (RAG) pipeline paired with LLMs. Includes automated revision quiz generation and interactive flashcard decks.

🚀 Launch Interactive Demo 📦 GitHub Repository Architecture: Hybrid RAG • FAISS • Llama 3
📋 Project Overview & Objectives
🎯 Problem Statement

Undergraduate IT students frequently work with massive 300+ page textbook PDFs and lecture slide decks across subjects like Operating Systems, Computer Networks, and Data Structures. Keyword search tools (Ctrl+F) fail to understand conceptual intent, while public LLMs frequently hallucinate fabricated answers without specific reference to the prescribed university syllabus.

🚀 Project Objectives
  • Semantic Document Ingestion: Chunk and vectorize multi-page academic PDFs with metadata preservation.
  • Hallucination-Free Q&A: Ground LLM responses strictly within retrieved high-cosine-similarity syllabus passages.
  • Automated Self-Assessment: Generate dynamic multiple-choice quizzes and active-recall flashcard decks directly from parsed chapters.
  • Source Attribution: Provide verifiable textbook citations and confidence scores for every answer.

🔄 Step-by-Step Workflow
1

Document Parsing & Recursive Chunking

Academic courseware PDFs are parsed into clean text strings, eliminating header/footer artifacts, and partitioned into overlapping 500-token chunks to maintain context across paragraph boundaries.

2

Dense Embedding & FAISS Indexing

Each chunk is transformed into a dense vector embedding using sentence transformers and indexed in a FAISS flat inner-product / cosine similarity index for rapid sub-10ms retrieval.

3

Semantic Query Execution

When a student enters a natural language inquiry, the query is converted into a matching vector representation and matched against the active courseware index to extract the top-k highest-similarity textbook sections.

4

Grounded LLM Synthesis & Assessment Generation

The retrieved chunks are bundled into a strict prompt template instructing the LLM to formulate an answer referencing only the verified excerpts, while also enabling 1-click generation of multiple-choice quizzes and revision flashcards.
