HealthSpan – A Personalized Dietary Nutrition System for Elderly Health Management

A comprehensive healthcare nutrition ecosystem engineered specifically for elderly health management. It integrates personalized medical diet planning with Llama 3 generative intelligence and FAISS vector similarity search to optimize senior wellness, avoid drug-nutrient contraindications, and bridge patient-caregiver monitoring.

📱 Flutter Mobile 🌐 React + Vite Web ⚡ FastAPI Backend 🧠 Llama 3 LLM 🔍 FAISS Vector Database 🗄️ PostgreSQL 🔒 Firebase Authentication 📊 USDA & NHANES Datasets
